# Blog, website, and misc. dumping ground

Hi! If you're reading this, please check out http://nerdsquad.xyz for the published site.

### Purpose
In short - I have a lot of ideas and half-finished projects, might as well publish something, right? For more thoughts on this read the into article on the published blog.

### Design

__Primary design goal: **Simplicity**__. I'm not getting paid to do this so it has to be fun and easy (or intellectually stimulating) otherwise I won't do it in my free time.

1. **Markdown Content**: I love markdown, so much so that all my daily notetaking and most work notetaking is in markdown. It's no surprise that I would choose to write blog content likewise. After all, for personal projects - if its not fun I'm not going to do it. 
2. **Static Site Generation**: I'm going to give Jekyll a try among the static site generators that I've quickly perused. I think getting up and working is more important that the exact details anway. All I really want is something I can get math rendering to work and some visual style control but I'm not picky in that department.
